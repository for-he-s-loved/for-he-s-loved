### 🤖 AI agents I've built

- **Ultron, a phone-call coding agent:** I call a number and describe a task out loud. An AI coding agent picks it up within seconds, works in the real codebase, reads progress back to me during the call, and phones me with a spoken summary when it's done. Only my number can give it tasks.
- **Cutflux agent tools:** a tool server (MCP) that lets Claude plan, cut, caption and render beat-synced video edits through Cutflux's own engine, so an assistant can do the editing on request.
- **Jarvis, a voice assistant:** wake word, speech in and out, and a language model that picks which tool to run: the time, weather, opening sites, playing YouTube, launching apps or checking the system. It can switch between several AI model providers or a local model.
- **Pixel, a local agent:** reasons and acts on my own computer with a local model and tool calling, with no cloud required. Jarvis hands it anything its built-in skills can't handle.
- **How I ship with agents:** I run AI coding agents on real production work, with guardrails. Changes go to staging first, get checked on real data, and production deploys need my sign-off and keep a rollback ready.
